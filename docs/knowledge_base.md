# Base de Conocimiento Data Governance

Las validaciones obligatorias son: columnas requeridas completas, fechas válidas, importes positivos y eliminación de duplicados.

Para Data Lineage se debe registrar origen, destino, proceso, timestamp y propietario del pipeline.

La capa de visualización Power BI debe consumir la tabla curada y mostrar volumen de incidencias, importe total y ratio de errores.

El circuito de IA agéntica orquesta: ingesta, calidad de datos, publicación y consulta RAG para soporte interno.
